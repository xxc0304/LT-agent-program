# 全屋设备状态查询

用于回答“家里有哪些设备”“客厅温度是多少”“有没有人”“门磁是否触发”“设备是否在线”等只读问题。

## 工作流程

1. 先调用 `list_devices` 确认设备实体和房间，必要时按 `domain` 过滤。
2. 再调用 `get_state` 读取目标设备的最新状态和属性。
3. 对多个设备逐个读取，不要根据历史对话猜测当前状态。
4. 回复设备名称、状态、关键属性、是否在线，并明确当前是 Mock HA 模拟数据。

## 设备类型

- `light`：灯光和亮度；
- `climate`：空调和温度设定；
- `cover`：窗帘和开合度；
- `lock`：门锁状态；
- `sensor`：温度、湿度等数值传感器；
- `binary_sensor`：人体、门磁、烟雾等开/关状态传感器。

## 安全边界

- 本 Skill 只查询，不调用 `control_device` 或 `run_scene`。
- 发现设备离线或状态异常时，说明证据并建议调用 `diagnose_device`；不得声称已经修复。
- 如果用户问最近的控制是否真正执行，可改用 `get_device_events` 查询动作事件；事件账本是进程内存，重启后会清空。
- 不要把“有人”“烟雾触发”等状态直接解释为入侵、火灾或医疗结论；需要由安全守护或其他专门 Agent 进一步判断。
