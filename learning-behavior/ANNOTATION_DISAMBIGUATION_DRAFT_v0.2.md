# 学习行为标签边界补充（讨论稿 v0.2）

状态：供项目组讨论，不是已冻结的公共契约。本文补充 `ANNOTATION_GUIDELINES_DRAFT.md` 中容易产生分歧的标签边界，不覆盖 v0.1，也不直接改变 Agent Event 或模型行为。

## 适用范围

本补充针对 SCB-Dataset 的**课堂整体场景**标注。活动标签表示画面中能确认存在的活动集合，不表示多数学生的活动，也不代表某个未指定目标儿童。无法从画面中确认的活动不要根据场景、位置或常识补猜。

本规则根据 2026-09-27 的 5 张模型试测暴露的问题整理。该批样本已用于观察模型输出，不能再当作未触碰的测试集来调整模型或提示词后复测。

## 活动标签边界

| 标签 | 正例条件 | 不足以单独支持该标签的证据 |
|---|---|---|
| `writing` | 清楚看到学生正在纸面、黑板或其他学习材料上书写/作答。记录动作本身，不因书写位置改变标签。 | 只拿着笔、手臂抬起但看不清是否书写。 |
| `presenting` | 清楚看到学生在向课堂展示或演示学习内容，例如指示/展示解题内容、面向课堂组织讲解动作，或有明确的课堂展示互动。静态图只记录可见的演示线索，不断言听众理解或实际发言。 | 仅仅站在讲台或黑板前；仅仅在黑板上写字。位置本身不等于展示。 |
| `peer_interaction` | 可见同伴之间的双向互动线索，例如互相回应的手势、共同操作材料、明显的面对面交流姿态。 | 多人同框，或一名学生在前方活动、其他学生看向前方。观看不等于互动。 |
| `raising_hand` | 可辨认学生举手作为课堂发言/回应动作，且不是完成当前任务所需的伸手动作。 | 站在黑板前写字、指向板书、拿取物品时抬手。 |
| `reading` | 可见学生查看并阅读书本、屏幕或纸面文字的姿态/动作。 | 仅仅低头；材料内容和阅读动作都无法辨认。 |

同一场景可以同时有多种活动。例如，一名学生清楚举手，另一名学生在黑板书写，可标 `writing` 与 `raising_hand`。如果黑板书写同时有清晰的课堂展示线索，可同时标 `writing` 与 `presenting`；没有展示线索时只标 `writing`。若场景足以支持某个活动、但不足以判断另一个可能活动，保留已确定标签，并把不确定点写入 `uncertainty_note`，不要用 `unknown` 覆盖已确认活动。

## `unknown` 与 `mixed`

`mixed` 表示观察到了至少两种不同情况；`unknown` 表示证据不足以判断。它们不是同义词，也不是置信度等级。

- 姿态 `mixed`：能清楚看到不同学生处于不同姿态，例如部分学生坐着、部分学生站着。
- 朝向 `mixed`：能清楚看到不同学生分别朝向不同对象/方向。
- 姿态或朝向 `unknown`：目标/人物太小、遮挡、画面模糊，或无法确定观察对象及其朝向。
- 只有部分人物可判断时，除非已经观察到至少两种明确状态，否则不要仅因“有人看不清”就标 `mixed`；可标 `unknown` 并记录原因。

朝向的判别对象需有可见依据：书本、纸张、黑板等学习材料对应 `toward_learning_material`；教师或明确的讲解者对应 `toward_instruction_source`。若教师与黑板重合、无法分辨视线对象，标 `unknown`。不能从朝向推断学生在听、专注或理解。

## 证据与复核

1. 每项标签写一条可见证据。活动证据尽量描述动作，不写心理结论。
2. 若一个画面里有多人，证据应指出标签来自哪类可见活动，例如“前排学生举手，讲台学生在黑板书写”。不要推断人数或身份。
3. `reviewer_confidence` 只表示标注者对当前标签证据的把握，不是模型置信度，也不应替代不确定原因。
4. 由不同标注者在看模型输出前独立标注。分歧按字段记录，先比较分歧类型，再仲裁；不要覆盖原始标注。
5. 如果项目组采纳本补充，应先冻结标签定义，再用新抽取且未用于本轮提示词调整的样本做独立复核/测试。不要在这 5 张试测样本上反复调提示词后报告分数。

## 本轮暴露的待确认事项

- 项目组是否同意将“黑板书写”本身与“课堂展示”分开，并要求有额外展示线索才能标 `presenting`。
- “其他学生看向讲台学生”是否只表示朝向课堂活动，而不自动构成 `peer_interaction`。本稿建议不标互动，除非有双向交流线索。
- 课堂整体图中 `mixed` 是否表示已观察到多种方向/姿态，还是只表示无法指定单一目标。建议采用前者；无法观察时用 `unknown`。

以上定义在项目组确认前均为建议，不应作为已统一的跨组契约。
