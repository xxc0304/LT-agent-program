## 逐例离线错误分析

本节只读取本机已保存的 5 张图片、人工暂定标签和模型预测，没有再次调用模型或上传图片。人工标签是单人复核结果；以下“分歧”不自动等于模型错，也不据此改写参考标签。图像观察只用于分析歧义，不作为新的真值。

| 样本 | 人工暂定活动 → 模型活动 | 其他维度 | 逐例观察与判断 | 置信度 / 耗时 |
|---|---|---|---|---:|
| `blind-002` | `reading` → `reading` | 姿态、朝向均一致 | 多名学生坐着看手中的书本，画面线索与阅读标签相符；本例没有明显分歧。 | 0.90 / 2.3 秒 |
| `blind-003` | `peer_interaction` → `presenting` | 姿态一致；朝向 `unknown` → `mixed` | 可见学生在黑板前操作板书、教师在旁、其他学生分组/移动。单帧没有清楚显示同伴之间的双向互动，因此人工 `peer_interaction` 依据较弱；模型 `presenting` 也需要额外展示线索才能确认。属于标签边界与参考标签都需复核的歧义例，不直接判模型错。 | 0.70 / 14.2 秒 |
| `blind-005` | `writing + raising_hand` → `presenting + raising_hand` | 姿态一致；朝向 `unknown` → `toward_learning_material` | 举手标签一致；`writing` 与 `presenting` 不一致。图像分辨率较低、前方人物和动作细节不够清楚，单帧难以稳妥判断是板书作答还是展示/讲解。朝向差异也发生在人工已标不确定的场景。应保留为边界案例，不凭本次模型输出来改标。 | 0.70 / 37.4 秒 |
| `blind-007` | `presenting + raising_hand` → `presenting` | 姿态、朝向均一致 | 前方学生在屏幕/黑板处展示内容，模型检出 `presenting`；画面中还可见其他学生举手，模型漏掉了这个场景级次要活动。属于较明确的多活动漏检例。 | 0.80 / 12.5 秒 |
| `blind-015` | `presenting` → `presenting` | 姿态一致；朝向 `unknown` → `mixed` | 前方学生正在操作/指示教学材料，`presenting` 与人工标签一致。朝向参考为 `unknown` 且人工注明不确定；模型将多人朝向判为 `mixed`，该判断不能仅凭当前单帧当作确定错误。 | 0.78 / 7.0 秒 |

### 分歧汇总

- 活动标签合计 TP=4、FP=2、FN=3：模型多报 `presenting` 2 次（`blind-003`、`blind-005`）；漏掉 `peer_interaction` 1 次（`blind-003`）、`writing` 1 次（`blind-005`）和 `raising_hand` 1 次（`blind-007`）。其中 `blind-003`、`blind-005` 的活动本身存在明显口径/画面歧义，不能把全部 FP/FN 解释为模型能力错误。
- 姿态 5/5 一致，但样本仅含 1 个 `seated` 和 4 个 `mixed`，类别覆盖不足，不能外推为姿态识别可靠。
- 朝向仅 2/5 一致。人工参考中 3 张是 `unknown`，模型在这 3 张上全部给出了确定类别（2 张 `mixed`、1 张 `toward_learning_material`），显示模型有“证据不足时仍作答”的倾向。后续应优先确认 `unknown` 与 `mixed` 的规则，并评估逐维度弃答；当前只有一个总置信度，不能证明它对朝向也可靠。
- 模型置信度为 0.70–0.90；5 张样本太少，且标签存在歧义，不能用它验证置信度校准，也不能单独把 0.8 之类阈值当成安全门槛。
- 平均耗时约 14.7 秒，最长约 37.4 秒（`blind-005`）。这只描述本次 API 请求，不代表稳定服务时延。

### 对标注口径的具体启发（仍为待讨论建议）

试测暴露出的重点与[标签边界讨论稿 v0.2](./ANNOTATION_DISAMBIGUATION_DRAFT_v0.2.md)一致：`writing` 应看见实际书写/作答；`presenting` 需要除“站在前面”之外的展示线索；`peer_interaction` 需要双向互动，不能由多人同框或学生看向前方推断。对课堂整体场景，还应明确一张图是否按“全班出现过的活动”多选，以及朝向按多数人、全体分布还是证据不足处理。

这些是结合 5 张图得到的复核提示，不是已经采纳的改标或跨组统一规则。5 张已用于试测和误差分析；若据此修改提示词/标签边界，就不能再把同 5 张当作独立验证集。

## 结论与限制

这 5 张是为覆盖阅读、举手、板书/展示和同伴互动而挑选的试测样本，不是随机抽样。姿态的 5/5 还受到样本分布影响：本批只有 1 张标为 `seated`，其余为 `mixed`。因此不能据此说姿态识别已可靠。活动识别的主要待查项是 `writing` 与 `presenting` 的边界、`peer_interaction` 的可见证据，以及举手是否被完整识别。朝向标签中 `unknown` 与模型倾向输出 `mixed` 的差异也需要复核规则。

当前结果只支持“接口和多维 JSON 输出可运行”，不支持自动评价儿童，也不应直接驱动设备。若要继续扩大样本，先固定标签口径并获得额外图片发送授权，再测剩余样本；正式性能结论还需要独立标注者复核和仲裁。
