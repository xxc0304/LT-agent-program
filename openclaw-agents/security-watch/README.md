# 安防看护 Agent（接口与 Skill 草案）

本目录对应甘特图 A-06 的事件/Skill 设计准备，不表示已经完成 A-07 的安全处置闭环，也没有自动注册到本机 OpenClaw。

## 职责边界

- 消费由 HA、传感器或边缘识别适配器提供的结构化事件；核验来源、时间、置信度、去重键和复核标记。
- 输出解释、复核请求或交给调度器的候选任务；不直接访问 HA，不自行解锁门锁、不解除告警、不把疑似事件说成已确认事实。
- 设备动作必须经过策略决策；高风险动作按安全组接口要求返回 `CHALLENGE` 并等待真实确认。
- 不接收或转发原始图像、视频、音频、身份信息或访问凭据。

## 事件样例

`common-contracts/examples/security-*-event.json` 提供门磁、人体移动、门锁状态、陌生人疑似和疑似跌倒的模拟事件。它们只用于契约/路由测试，不是实际传感器或识别模型结果。

## Skill

- `skills/safety-event-triage/SKILL.md`：结构化安全事件分诊规则。

本草案需要安防负责人和数据安全组确认正式事件名、严重级别、数据等级、升级/通知方式及 `PolicyDecision` 接口后，才能作为跨组冻结版本。
