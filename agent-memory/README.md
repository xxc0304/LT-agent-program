# 家庭偏好记忆 MVP

`src/memory-store.js` 提供家庭边缘端的本地偏好存储，当前只支持舒适温度、睡觉时间和起床时间。当前数据结构版本为 0.2，可读取并安全标记 0.1 的旧候选供重新观察；默认文件名保留为兼容路径 `family-memory-v0.1.json`。它不是向量知识库，也不保存原始对话、设备瞬时状态、儿童图片/视频、API Key 或密码。

## 当前实现

- 用户明确要求长期记住并授权后，可保存已确认偏好；相同对象/房间/日期范围的新值会覆盖旧值。
- 重复作息观察先进入 `observing` 状态；默认至少 3 个不同本地日期、每次置信度不低于 0.8，才形成 `pending_confirmation` 候选。同一天多个事件只计一次，作息值关联家庭 IANA 时区并按周内/周末区分；观察时间暂按最近 15 分钟归并，需在用户确认时说明为近似值。必须先获得用户同意采集习惯；候选不会被 `getPreference()` 返回，也不能用于控制，直至用户明确确认。
- 支持查询（精确房间/日期范围优先，随后回退到通用偏好）、列出、删除和过期清理。
- 默认文件位置在 `LOCALAPPDATA/LT-agent-program/family-memory-v0.1.json`（Windows），或 XDG 数据目录；可通过 `FAMILY_MEMORY_PATH` 指定。请勿将它设到 Git 仓库内，也不要用 CtxHop/Git 同步未经批准的家庭记忆。
- 活动记忆文件仍是本地 JSON，不是加密数据库；Windows 上应依赖受限的用户目录 ACL 和设备磁盘加密。模块通过同目录 `.lock` 文件阻止另一进程同时读写，发生竞争时读操作报 `MEMORY_STORE_LOCKED`、写操作返回同码失败；若进程异常退出留下锁，会失败关闭，需先确认写入进程已结束，再由管理员/用户人工检查锁文件后处理。原子替换的兼容路径还可能短暂产生 `.tmp`/`.backup` 旁文件；异常退出残留时也应按记忆文件同等级保护。该锁只适用于本机文件系统，不支持网络盘或跨设备共享目录。
- 新增显式调用的加密备份/恢复库 `src/encrypted-backup.js` 与终端入口 `src/backup-cli.js`：使用 scrypt 派生密钥和 AES-256-GCM 完整性认证；创建备份时持有源文件锁，恢复先验证认证与记忆 JSON/schema；备份和恢复目标均使用“仅新建”策略，不覆盖已有文件。命令是 `npm run backup -- create <家庭记忆.json> <新建备份.enc.json>` 和 `npm run backup -- restore <备份.enc.json> <新建恢复文件.json>`；口令只在交互终端隐藏输入，创建时需输入两次，至少 12 UTF-8 字节，不通过参数、环境变量或管道读取，也不记录或保存。尚未对真实家庭记忆执行备份或恢复。还原后的活动文件仍是明文 JSON，必须由 NTFS ACL/磁盘加密保护；备份介质应是受限的本地/离线介质，不能放普通云盘、Git 或 CtxHop。加密备份也不替代独立的口令安全保管。
- 新增 `src/routine-trigger.js`：外部本地调度器可按时区轮询已确认的睡觉/起床偏好，在默认 1 分钟窗口内生成稳定的 `routine_due` Event 和 `dedup_key`；同一偏好、同一本地日期的重试会生成相同事件。它默认 `scheduleAuthorized: false`；即使单独授权启用，也只返回事件，不建系统定时器、不发送通知、不控制设备，实际通知通道仍由经授权的外部调度/通知适配器负责。
- 删除会从活动记忆文件移除记录，不等同于对 SSD、文件系统快照或用户另行保存的备份进行安全擦除；如果曾建立备份，应按相同保留/删除策略处置备份副本。

## 暂不保存

不保存原始聊天文本、原始图片/视频、儿童身份信息、每分钟设备状态、凭据，或只有一次/低置信度的行为推断。过期推测候选默认 30 天清理；已确认偏好可设置过期时间，也可由用户随时删除。

## 运行测试

```powershell
Set-Location agent-memory
npm test
npm run demo
```

当前模块已通过设备管家 OpenClaw 插件源码暴露 7 个记忆工具（查询、列出、显式保存、结构化作息观察、确认、作息预览、删除），并由单元测试和插件静态校验覆盖。作息观察工具接受带时区的 `occurred_at`，由代码计算家庭本地日期并归并到 15 分钟区间，不再让模型直接填写本地日期；已确认的舒适温度可进入 `plan_scene` 只读个性化建议。新增到期事件评估器可供外部定时器调用，但当前没有活动定时器或通知发送器；若未在可信本地配置中单独设置授权，它会失败关闭并不生成事件。

自动采集日常事件并归纳作息仍未接入；本地 Mock 接口要求上游提供获得授权的结构化 `routine_observation`，累计至少 3 个不同本地日期且置信度达到 0.8，才形成待确认候选。作息时间暂按最近 15 分钟归并，候选必须由用户确认；到期事件评估只产出幂等 `routine_due` Event，不启动定时器、不发送通知、不控制设备。Gateway 重载后实际调用这些工具的运行时核验也应单独完成，不能用插件静态校验代替。

部署前仍需在目标设备核验本地文件 ACL/磁盘加密，并确定经授权的备份/恢复流程、时区/成员范围，以及是否允许跨设备同步。活动家庭记忆文件仍无应用层加密；禁止把家庭记忆文件提交 Git、放进普通云盘或 CtxHop。加密备份库仅在临时测试数据上验证，实际数据的备份/恢复须另行获授权并先选定受控目标。
