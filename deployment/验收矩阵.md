# Agent 集成验收矩阵

## 1. 验收结果如何表述

每一项必须标明环境（单元测试 / Mock / OpenClaw 隔离 Gateway / 真实 HA / 物理设备）和代码版本。不能把更低层级的通过结果升级描述为真实设备已通过。

| 验收级别 | 要验证的内容 | 通过后能说明 | 不能说明 |
|---|---|---|---|
| 公共契约校验 | Schema、兼容字段、有效/无效样例 | 本仓库当前草案格式能被校验器处理 | 其他组已确认字段或生产系统兼容 |
| 模块单元测试 | Agent 规则、调度、设备动作门禁、存储等 | 被测代码分支按测试条件工作 | Gateway 已加载、真实协议可用 |
| Mock 验收 | 合成事件经能源管家、调度器和设备管家完成 Mock 设备操作并回读 | 本地软件链路有端到端演示证据 | 真实传感器可信、HA/物理家电运行正常 |
| OpenClaw Gateway 验收 | 目标版本中的插件加载、工具可见、自然语言调用和澄清交互 | 该 Gateway profile 下指定对话路径可用 | 真实 HA 或家庭数据已接入 |
| 真实 HA 只读验收 | 认证、状态/Registry 读取、实体映射、断连处理 | 指定 HA 实例可读并返回所见数据 | 写操作或所有集成/设备都可靠 |
| 真实设备写入验收 | 受控测试实体操作、回读、失败/恢复/审计 | 指定设备/动作在指定版本与网络条件下通过 | 所有型号、所有家庭环境均通过 |
| 企业生产验收 | 权限、隐私、可靠性、恢复、升级/回滚、负载、安全审查 | 仅在企业签字的范围内可上线 | 未列入矩阵的功能自动通过 |

## 2. 当前可复现的本地验收（2026-10-31）

本次整包验收环境为 Debian 12、Node.js 24.22.1、OpenClaw `2026.7.1-2`。ZIP 完整性检查通过，设备管家和平台编排插件均通过 OpenClaw CLI 校验，Linux 验证入口 11/11 阶段通过：582 项单元测试、11 项设备管家 Mock 验收通过。Windows 部署包与模拟安装流程检查 123/123 通过。

OpenClaw `2026.7.1-2` 依赖树的 npm audit 报告 17 项（1 严重、10 高危、6 中危）。项目组已明确接受这一固定版本的审计告警作为已知风险；没有升级 OpenClaw，也没有修改其依赖。风险接受不等于漏洞修复，审计数量可能随 registry 数据变化。

目标 OpenClaw 隔离 Profile 的插件加载、工具注册、只读 RPC、SQLite 跨 Gateway 重启读取，以及指定的 A2A/自然语言场景已有单独验证记录。当前验收未接入真实 HA 或家电，也未在 Ubuntu 持久主机做部署验收。

复跑本地/Mock 验收：

    node deployment/verify-agent-stack.mjs

脚本覆盖公共契约兼容和样例、设备管家测试及 Mock acceptance、能源管家测试、家庭记忆测试、多 Agent 编排器测试，以及“占用事件 → 能源管家 → 设备管家 → Mock HA”集成演示。完整验收结果、固定版本和风险处理记录见 `docs/linux-development-and-validation.md`。

建议归档脚本输出、Git commit/hash、Node/OpenClaw 版本、合成输入、trace、TaskReceipt 和最终回读状态。若脚本无法运行或依赖未安装，应记录失败步骤，不得用旧报告替代本次结果。
