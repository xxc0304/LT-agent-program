# Agent 集成验收矩阵

## 1. 验收结果如何表述

每一项必须标明环境（单元测试 / Mock / OpenClaw 隔离 Gateway / 真实 HA / 物理设备）和代码版本。不能把更低层级的通过结果升级描述为真实设备已通过。

| 验收级别 | 要验证的内容 | 通过后能说明 | 不能说明 |
|---|---|---|---|
| 公共契约校验 | Schema、兼容字段、有效/无效样例 | 本仓库当前草案格式能被校验器处理 | 其他组已确认字段或生产系统兼容 |
| 模块单元测试 | Agent 规则、调度、设备动作门禁、存储等 | 被测代码分支按测试条件工作 | Gateway 已加载、真实协议可用 |
| Mock 验收 | 合成事件经节能 Agent、调度器和设备管家完成 Mock 设备操作并回读 | 本地软件链路有端到端演示证据 | 真实传感器可信、HA/物理家电运行正常 |
| OpenClaw Gateway 验收 | 目标版本中的插件加载、工具可见、自然语言调用和澄清交互 | 该 Gateway profile 下指定对话路径可用 | 真实 HA 或家庭数据已接入 |
| 真实 HA 只读验收 | 认证、状态/Registry 读取、实体映射、断连处理 | 指定 HA 实例可读并返回所见数据 | 写操作或所有集成/设备都可靠 |
| 真实设备写入验收 | 受控测试实体操作、回读、失败/恢复/审计 | 指定设备/动作在指定版本与网络条件下通过 | 所有型号、所有家庭环境均通过 |
| 企业生产验收 | 权限、隐私、可靠性、恢复、升级/回滚、负载、安全审查 | 仅在企业签字的范围内可上线 | 未列入矩阵的功能自动通过 |

## 2. 当前可复现的本地验收

运行命令：

    .\deployment\Verify-Agent-Integration.ps1

脚本覆盖公共契约兼容和样例、设备管家测试及 Mock acceptance、节能 Agent 测试、家庭记忆测试、多 Agent 编排器测试，以及“占用事件 → 节能 Agent → 设备管家 → Mock HA”集成演示。

建议归档脚本输出、Git commit/hash、Node/OpenClaw 版本、合成输入、trace、TaskReceipt 和最终回读状态。若脚本无法运行或依赖未安装，应记录失败步骤，不得用旧报告替代本次结果。
