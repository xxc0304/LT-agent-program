# 使用与操作手册

## 1. 使用场景

- 开发/联调人员：运行契约校验、模块测试和合成事件 Mock 闭环。
- 演示人员：在 OpenClaw 插件已加载、工具已授权并明确选择 Mock 后端后，通过自然语言请求设备查询或演示工具。

Mock 演示不会控制真实家电。没有可信 HA 事件适配器时，不要把手工输入的传感器事件称为真实家庭传感器事件。

## 2. Linux 安装与验证

在 Ubuntu 24.04、Node.js 24 的包根目录运行。电脑上需已经安装 OpenClaw `2026.7.1-2`，并确认 `openclaw` 命令当前指向准备安装的 Profile。

运行本地/Mock 验证：

```bash
npm --prefix device-manager ci
node deployment/verify-agent-stack.mjs
```

只看安装计划（默认只读，不安装依赖、不改 Profile）：

```bash
node deployment/install-agent-stack.mjs
```

确认计划中的 Profile 和 Agent 后再安装：

```bash
node deployment/install-agent-stack.mjs --apply
```

安装前需准确输入 `INSTALL`；配置完成后，只有再明确输入 `RESTART` 才会安全重启 Gateway。首次部署建议将 `openclaw` CLI 指向隔离 Profile。安装器不会安装或升级 OpenClaw、修改模型/API 凭据，也不会覆盖冲突的插件来源或 Agent 工作区。

需要 SQLite 记忆时显式添加 `--enable-sqlite-memory`；部署后也可在包根目录运行 `node deployment/verify-agent-stack.mjs --skip-demos` 只做测试，不跑演示。

## Windows 兼容方式

Windows 电脑仍可使用根目录 `Install-Agent-Stack.cmd` 或 `deployment/Install-Agent-Stack.ps1`。它们是兼容入口，不属于项目的 Linux 部署基线。

## 3. 一键演示主链路

```bash
npm --prefix energy-saving run demo
npm --prefix multi-agent-orchestrator run demo
```

演示过程：

1. 创建独立 Mock HA，并将客厅灯和插座初始化为开启。
2. 输入一条合成的“客厅无人 10 分钟”占用事件。
3. 多 Agent 调度器把事件交给能源管家。
4. 能源管家生成设备任务，交给设备管家运行时。
5. Mock HA 执行关灯/关插座；系统回读状态并输出 trace、任务回执和最终状态。

预期能看到 SUCCEEDED、两个 Agent 参与、两条任务回执成功且最终设备状态为 off。该结果证明的是本地逻辑和 Mock 链路，不是传感器准确率、LLM 判断效果或真实 HA 控制。

## 4. OpenClaw 对话演示

Linux 部署完成并安全重启 Gateway 后，确认插件运行时检查显示已加载，再留在 OpenClaw 平常聊天的主 Agent 中进行对话。Agent 注册和工具权限由安装器通过 OpenClaw 官方 CLI 配置；模型与凭据沿用当前 Profile，脚本不会更改。

可以用以下类型的自然语言验证只读交互：

- “列出目前登记的设备。”
- “查询客厅灯现在是什么状态。”
- “先预览回家场景，不要执行。”

用户明确授权后才可执行需确认的计划。不要让模型凭空构造传感器事实；由公开对话工具提交的事件不自动获得可信传感器身份。真实事件入口须由经认证的 HA/消息接入适配器提供。

若插件未加载、工具不可见或版本不匹配，先检查本机 OpenClaw 版本、插件 runtime inspect 和 Gateway 日志；不要通过放宽全局工具权限来绕过问题。

## 5. 如何看演示结果

- trace：一次事件经过的阶段、涉及的 Agent 和总体状态。
- planned_tasks：业务 Agent 提出的任务，不单独证明设备已经执行。
- receipts：设备管家执行后的回执；有失败或需确认时查看 reason/error 字段。
- final_states：从后端再次读取的设备状态。只有回读满足目标，才能报告“验证成功”。
- CHALLENGE / CLARIFICATION_REQUIRED：等待用户补充或确认，不等于已经执行，也不代表整项任务被遗弃。

## 6. 演示记录建议

记录运行日期、代码提交/版本号、命令、脚本汇总、演示输出中的 trace/回执/回读状态，以及明确的环境标注“Mock”。截图时不要展示令牌、个人 OpenClaw profile、家庭记忆文件或任何真实家庭数据。
